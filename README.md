# Scholarship Monitoring System

A web-based Student Scholarship Monitoring and Academic Compliance System developed for the Systems Analysis and Design laboratory activity.

The system is designed to help scholarship personnel manage scholars, scholarship programs, academic requirements, grade submissions, verification, and scholarship compliance status.

---

## System Purpose

The Scholarship Monitoring System provides a centralized way for scholarship personnel to monitor student scholars and their academic compliance.

The system supports the following core process:

```text
Scholar Registration
        ↓
Scholarship Assignment
        ↓
Grade Submission
        ↓
Grade Verification
        ↓
Compliance Evaluation
        ↓
Scholar Status Monitoring
